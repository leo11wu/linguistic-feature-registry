# 测量与建模原则

## 范围

本轮是目的性资源盘点，依据官方文档、作者资源、指标表、论文和勘误逐层补查；并非穷尽数据库检索的系统综述。定义用于筛选和实施前核对。

## 把测量口径写入配置

至少保存观察单位、token／wordform／lemma、标注方案、标点过滤与重编号、分母、尺度、窗口、聚合权重、阈值、随机种子、资源版本和模型身份。同名输出不保证这些条件一致。

例如 DPnorm 在不等长分块中需要核对勘误后的分母；ΔP 必须区分两个方向；Frazier 逐词均值与最大连续三词总分不能混同。具体定义见论文操作化表。

## 外部资源与缺失

参考词频是相对于特定语料的频率。词形频率、lemma频率、语域分区和词族频率分别登记。人工常模记录其原评分，不把预测值补成同一列。

每种资源保存有效词数、词次覆盖率和词型覆盖率。均值只在合格命中词上计算，未命中、无定义、解析失败和真实零分别处理。按组检查缺失分布，不以全样本平均覆盖代替组间测量可比性。

默认词次均值会给重复词更大权重；词型均值等权。词型是wordform还是lemma须写入字段名。对照资源时先固定共同覆盖词集，再另报各资源完整覆盖版本。

## 向量与语言模型

静态词向量平均、LSA和句编码器产生不同操作化；不同空间的标准化不能证明测量等价。句对余弦先解释为所选编码器下的语义相似度。连贯性需要另外通过人工或任务证据验证。

固定模型下的surprisal、PPL和PLL属于模型相关评分。保存权重提交、tokenizer、词／子词对齐、上下文、BOS、滑窗、精度和归一化。生成模型与评分模型的重合可能影响跨模型文本比较，需要在设计中考虑。

## 两类模型用途

规律拟合保留目标语料自身的词型频数、频谱、增长顺序、词位置序列和层级分割。外部词表频数不能替换这些观测。

解释／预测建模先确定观察单位和抽样层级。训练内完成填补、缩放、选特征、降维、自建IDF、词块表或聚类；按研究的泛化目标分组验证。相关性、预测提升与机制或因果识别是不同结论。

确定性冗余需要单独处理，例如 Root TTR 与 CTTR、平均NLL与PPL，以及某些同图入／出度均值。样本量和理论问题决定最终变量组合。

## 核验边界

来源表与操作化表分别记录核验范围。例如NDD原论文全文尚未取得；word-l2r读取摘要及正文索引；部分MTLD变体规则来自维护者文档。方法核对、文件校验、数值复现和目标语料效度验证应分开报告。

本快照未运行提取器，也未拟合用户语料。`scripts/validate_registry.py`只检验目录和发布文件的一致性。
