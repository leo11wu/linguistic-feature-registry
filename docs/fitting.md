# 提取与拟合工作流 · 0.2.3

## 两个入口

提取从TXT/CSV生成可追溯的词、句、文档与语料组测量。拟合读取保存的观测或外部CSV，不调用spaCy、句向量或语言模型；更换模型不重跑文本解析，结果保存到独立新目录。无新增大型依赖或历时功能。

目录中的QL01–QL08移至拟合。voc-D内部拟合、依存随机基线与固定预训练模型评分属于指标定义，继续随提取执行。

## 可复用的观测

下表为逻辑表名。0.2.2默认将大于等于1 MB的表压缩为`.csv.gz`，内容与精度不变；拟合页读取`analysis_tables.json`中的实际路径，也允许直接导入`.csv.gz`。旧版普通CSV继续可用。逐对句子明细默认不导出，不影响这些拟合数据。

| 表 | 每行观测及用途 |
| --- | --- |
| `tokens.csv` | 原词/标点节点，含位置、句号、词形/lemma键、字母数；供词级分析或重新分块 |
| `observations/sentence_measures.csv` | 一句话的词数、句内平均字母词长；供Menzerath等句级关系 |
| `observations/word_lengths.csv` | 文档内一种正字母长度及词次频数；分布频数列选`count` |
| `observations/rank_frequency.csv` | 统计组内一个词型及排名、频数；供Zipf排名曲线 |
| `observations/frequency_spectrum.csv` | 一种词频及具有该频率的词型数；频数列选`types`，供LNRE等 |
| `observations/vocabulary_growth.csv` | 输入序列某一前缀的累计词数/词型数；累计点相互依赖 |
| `observations/abbreviation.csv` | 统计组内一个词型及频率、键的字母数；供简短律关系 |
| `observations/taylor_points.csv` | 一个词型在固定词数完整窗口中的均值、总体标准差；另报窗口数、末尾丢弃词数 |
| `features.csv` | 一篇文档的汇总特征 |
| `pair_features.csv` | 一个文本对的特征；不能复制成两条独立观测 |
| `corpus_features.csv` | 一个目标语料组的测量；不能复制到每篇文档制造样本量 |

词长分布与句内词长使用原词字母数；词长分布排除零字母token。排名词频和简短律使用当前wordform/lemma键；长度口径分别记录。`document_metadata.csv`供按文档标识连接元数据。自动标注并非人工真值。

## 拟合操作

1. 选择完整提取结果目录及观测表，或直接导入CSV。0.1版结果可选择其已有CSV，不假定具有新表清单。
2. 确认每行的观测单位。选择变量关系/规律曲线或离散分布，再选择X/Y或观测值。
3. 选择全部行合并或按标识列分别拟合；必要时指定数值范围及权重/频数。
4. 选择候选模型与独立输出目录。每个候选使用相同纳入行；不为满足某模型定义暗中额外删行。
5. 检查逐项状态、纳入行、参数、图形及残差；失败和缺失不填零。“查看图形与报告”在应用内打开离线预览。

改变数据表、变量、范围或候选模型会清空界面上的上一轮结果，需重新拟合。已经保存的文件不删除，可在运行记录中打开。

关系模型支持线性、原尺度幂函数、对数空间幂函数、指数、Zipf、Zipf–Mandelbrot、Heaps、Menzerath–Altmann及Pearson/Spearman相关。两种幂函数的误差目标不同，分别命名；最小二乘权重是相对精度权重，相关不接受权重。

离散分布支持泊松、零截断泊松、从1开始的几何和负二项，按正整数频数加权最大似然估计。比例不能冒充频数；零截断似然与筛掉零后使用普通泊松不同。词频谱另支持zipfR的fZM、ZM和GIGP，外部CSV需确认“频次—词型数”口径。

线性和对数空间幂函数只用已有NumPy；其他常规拟合复用可选SciPy，LNRE复用独立R/zipfR。

## 拟合输出及边界

- `selected_observations.csv`保存实际纳入值、组、权重和来源CSV行号。
- `fit_config.json`保存变量、筛选、候选模型、源表哈希、提取签名与测量配置。
- `fit_results.csv`按组和模型输出参数、状态及失败原因；新增字段见[统计量与适用条件](fitting_statistics.md)。关系同时报告误差、区间和相容似然下的信息准则；常规分布报告拟合优度与偏差量；LNRE使用独立的多元拟合优度。
- `fit_results.json`保留完整结构化结果，包括参数协方差、区间、诊断说明、类别合并与可用的LNRE期望词频谱。
- `fit_predictions.csv`保存观测、预测、残差、绝对/平方误差及适用时的对数/标准化/Pearson残差；相关仅保留散点，不生成虚构回归曲线。
- `fit_gof_bins.csv`保存常规离散分布的完整支持合并类别、实际/期望频数与χ²贡献。`upper`留空表示无限上尾。
- `fit_expected_spectrum.csv`在LNRE返回期望谱时保存实际与期望词型数。
- `fit_manifest.json`保存版本、输入/纳入/排除数量、状态和文件哈希。
- `report.html`是离线统计表、参数区间表、比较表及图形报告。最多展开前12个组—模型组合；总览表、CSV和JSON保存所有模型。绘图抽点保留前64个X最小的点，并结合均匀/对数覆盖，正值曲线同时展示双对数视图及原尺度残差。

AIC/BIC仅适用于同组观测、相同响应量和相容的完整似然。原响应尺度高斯回归与加入Jacobian的对数正态回归可在该条件下比较，不能直接把未经修正的ln响应AIC混入。相关p值、关系RMSE和分布AIC不是可互换的评分。普通排名曲线不自动当成归一化概率分布执行Pearson检验；LNRE不使用普通独立类别卡方。当前不自动做幂律尾部选择/检验、bootstrap、聚类稳健误差、混合效应或因果识别。参数估计成功不等于规律得到验证，增长点与同文档内词句的抽样依赖未自动处理。

## 参照、配对与网络

提取页可将所有目标文本合并，或按非空元数据列划分统计组。本批参照在各组内部建立：搭配和词块含当前文档；JS散度以组内其他文档为参照。离散度默认每篇文档一块，也可选择元数据分块列。

完整提取的`reference.json`冻结本批目标自身的词频、2–4词序列、文档分布与分块计数，不含原文。后续选择该目录作为外部参照，目标文本不更新参照。参照身份/哈希记入运行配置，实际统计另存`reference_applied.json`；当前结果的`reference.json`仍只表示当前目标。词形/lemma及固定基础标注方案必须匹配。外部参照使用其建立时的分块。

预测研究应先划分数据，仅用训练部分建立参照，再冻结应用。全批发现词块适合描述该批，不能直接视为独立测试特征。

LSM需明确配对列，每个非空编号恰好两篇文本；不合条件在`pair_status.csv`标记，不猜测配对。配对可跨语料统计组，每对只输出一次。

网络只使用目标组文本，不借用外部参照的边。可选句内相邻或最大词距窗口、有向/无向、边最低频次；窗口不跨句。路径、聚类和介数按二值边；出现次数另存为强度。排除自环、保留孤立节点，保存边表、节点表与构造配置。

Biber维度和SID应用已有规则、标准化参数、权重或训练簇，不负责发现因子或重训簇；这些上游建模需独立完成。
