# 验证范围

本应用的验证分为公式核对、资源/模型试跑、文件与界面流程、批处理性能。它们不代表在具体目标语料上已经验证构念效度或人工标注准确率。

## 已执行的软件检查

- 数学样例覆盖TTR变体、MTLD边界、HD-D、Yule/Simpson、2012修正版DPnorm、双向ΔP、logDice、UID、实体网格及有向图不可达条件。
- 论文示例树核对Yngve/Frazier逐词分数；L2SCA结构计数使用固定的纯Python上游查询。
- LAL真最小长度与20个小树的穷举结果一致；在完整Mac包中独立运行，不依赖开发机的库路径。
- Pythia410M、BERT PLL、MPNet、原始PTB解析和Stanza共指已以真实下载权重试跑，模型修订固定。词表接口使用明确标记的合成测试表，未冒充真实常模数据。
- R 4.5.3官方包签名与公证核对通过；隔离重定位后的zipfR 0.6-70完成FZM拟合。
- 文件检查覆盖BOM、引号、换行、空文本、重复编号、Unicode路径、原文件保留、部分缺失、取消和续算。

安装包的实际体积、测试数量和批处理测量值记录在 `metadata/verification.json`。性能语料为重复结构的合成英文，使用常用组合；不能据此预测所有真实语料和重型模块的速度。

## 仍需研究层校准

3个目录条目保留方法待核：修订D-Level、原始NDD、完整CPIDR/DEPID规则。PLL-word-l2r与MTLD-MA等变体状态单列，不能用基础版本冒充。

Apple校对结果是系统检查器命中项，未验证为人工错误真值。词表覆盖、心理常模尺度、分词/句法准确率、句向量及LM分数的解释，均应按研究语域作小样本检查。

当前机器为Apple Silicon、macOS 15.7.4。最低部署目标为macOS 13；其他组员机器的实机安装与数值一致性尚需组内试用确认。
