# 数据字典

所有 CSV 的第一行为字段名。当前字段为文本；公式和缺失处理说明作为定义保存，不是 Excel 可执行公式。机器读取应使用 UTF-8 BOM 兼容方式。

## 指标目录

| 字段 | 含义 |
| --- | --- |
| feature_id | 稳定的目录标识，如 LEN01；指标变体通过此字段关联。 |
| 类别 | 带序号的内容分类。 |
| 英文名称 | 英文方法或指标族名称。 |
| 中文名称 | 中文名称。 |
| 定义或计算口径 | 筛选与实施核对所需定义；未必构成完整执行规范。 |
| 观察层级与单位 | 词、句、篇、词项或语料层级及单位。 |
| 提取入口 | 软件、词表、模型或自定义路径。 |
| 实施分组 | 原目录的资源／实现分组，不等于本轮资源选择优先级。 |
| 建模与测量注意点 | 长度、分母、缺失、冗余和效度等限制。 |
| 跨语言说明 | 迁移边界与可比性说明。 |
| 来源ID | 逗号分隔的 R 编号，关联 sources.csv。 |
| 来源链接 | 一个或多个 URL，字段内可换行。 |
| 核验状态 | 来源支持及实际核验范围，不表示提取器已实测。 |

## 论文操作化

| 字段 | 含义 |
| --- | --- |
| spec_id | 操作化记录的唯一编号，如 P001。 |
| feature_id | 对应总目录的 feature_id。 |
| 操作化名称 | 当前版本或聚合方式名称。 |
| 与总目录关系 | 新增指标族或已有指标细分等关系。 |
| 来源关系 | 提出、后续使用、修正或本目录迁移建议。 |
| 定义与公式 | 定义和公式；符号与单位结合下一字段读取。 |
| 观察单位与符号 | 观察单位及符号含义。 |
| 分母与归一化 | 分母、尺度和归一化。 |
| 聚合方式 | 词／句／篇等层级的汇总方式与权重。 |
| 预处理与参数 | 分词、标注、过滤、窗口、阈值等规则。 |
| 方向与边界 | 数值方向、零分母与适用边界。 |
| 不能混同的版本 | 同名但不可互换的版本。 |
| 原文语言与任务 | 原论文使用的语言与任务。 |
| 英语迁移判断 | 迁移到英语的证据或限制。 |
| 提取与实测状态 | 提取路径是否实测。 |
| 来源ID | 逗号分隔的来源编号。 |
| 原文定位 | 章节、表格、图或公式位置。 |
| 核验状态 | 全文、摘要、文档等核验范围。 |
| 待核细节或变更 | 尚待核对的参数、原文差异或本目录补充约定。 |
| 来源链接 | 来源页面或 PDF 链接。 |

## 资源选型

| 字段 | 含义 |
| --- | --- |
| selection_id | 唯一选型编号，如 RS02。 |
| 资源模块 | 资源用途。 |
| 使用级别 | A/B/C/D/E 实施优先级，非效度等级。 |
| 关联指标ID | 逗号分隔的关联 feature_id。 |
| 选定资源或方案 | 当前首选资源或条件方案。 |
| 输出的测量含义 | 该资源支持的测量解释。 |
| 选择理由与替代方案 | 选择依据、替代方案与未选原因。 |
| 匹配与计算规则 | 匹配单位、公式和聚合口径。 |
| 缺失及质量控制 | 缺失、覆盖与质量检查。 |
| 版本与运行负担 | 拟固定的版本及资源负担；尚未实测的成本须保留说明。 |
| 启用条件及适用边界 | 启用条件和研究范围。 |
| 来源ID | 逗号分隔的来源编号。 |
| 来源链接 | 来源链接。 |
| 核验状态 | 来源核验与提取实测的区别。 |

## 来源与建模说明

`sources.csv` 包含来源ID、工具或资源、来源类型、支持范围、版本与书目信息、网址、核验边界。

`modeling_guidance.csv` 包含主题、事项、建议或状态、说明、依据。依据列可包含来源编号、选型编号或本目录方法建议；它不是只允许来源ID的外键列。

## 关联与计数

`feature_id`、`spec_id`、`selection_id`、来源ID分别在所属表内唯一。一个目录条目可对应多个操作化；一项资源选择也可关联多个条目。聚合、方向、资源或参数变体不自动构成新的语言学构念。

资源优先级与原目录实施分组为不同字段。A 优先建设、B 按问题启用、C 校准后启用、D 平行复核、E 暂缓默认；这些建议不构成工具已安装、资源已下载或效度已确认的声明。
